# Marketing Content

1. 核となる知見を1つ抽出する。
2. 対象読者と、読後に取ってほしい行動を決める。
3. 事実の根拠を保持する。
4. 文面を複製するのではなく、チャネルごとに深さを変える。
5. 裏付けのない数値や誇張した主張を避ける。
6. チャネル別variantを作る前に、再利用できるsource-of-truthのメモを作る。

## 注意

- 一次情報（検証ログ・公式資料）へのリンクを残す。
- 公開前の検証は loop-engineering skill の `loops/business-review.md` を使う。
