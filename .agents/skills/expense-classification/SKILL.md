# Expense Classification

## 重要

このskillは証憑を整理するもので、税務相談の代わりではない。税務上の判断や年度固有の結論は、国税庁の資料など現行の一次資料で確認する。

## 出力項目

- 日付
- 支払先
- 内容
- 税込金額
- 通貨
- 勘定科目の候補
- 事業使用割合
- 請求書 / 領収書の証憑
- 適格請求書（インボイス）の該当有無（関係する場合）
- 不確実性 / 要確認フラグ

## 原則

- 領収書のデータを推測で埋めない。無い項目は空欄にして要確認フラグを立てる。
- 家事按分の割合は根拠（使用実態）を添える。
- 科目の判断に迷うものは候補を複数示し、確定させない。
