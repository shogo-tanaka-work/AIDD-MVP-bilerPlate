# Sales Proposal Workflow

1. クライアントの目的と、達成したいビジネス上の成果を抽出する。
2. 明示された要件と、こちらが置いた前提を分けて書く。
3. 技術的な適合性と未知の要素を評価する。
4. 成果物と、対象外とするものを定義する。
5. 作業パッケージごとに工数を見積もる。
6. 不確実性に応じたcontingencyを加える。
7. 受け入れ基準を決める。
8. リスクの高いスコープにコミットする前に、確認事項を列挙する。
9. 価値に焦点を当てた簡潔な提案書を起草する。

## 注意

- 見積の根拠（前提・除外・単価）を提案書の中で追跡できるようにする。
- 未確認の前提を確定事項として書かない。
- 仕上げの検証は loop-engineering skill の `loops/business-review.md` を使う。
